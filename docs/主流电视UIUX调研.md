# 主流电视应用 UI/UX 与用户体验调研

> 调研目标：梳理市面上主流电视应用/平台的 UI/UX、用户体验与易用性设计（明确排除广告变现内容），为自有电视应用提供 gap 分析与优化方向输入。
>
> 调研日期：2026-08-09

---

## 一、调研范围与方法

- **对象**：国内主流直播类 App（电视家、小鲸直播、火星直播、HDP 直播、星火TV/DIYP 生态、开源 my-tv）与全球平台级 TV 体验（Google TV/Android TV、Apple tvOS、Netflix、YouTube TV、Amazon Fire TV、TiviMate）。
- **方法**：① 平台官方设计规范与工程博客（Google/Apple/Amazon/Netflix）为"可核实证据"；② 公开产品形态、功能页、用户口碑归纳为"产品形态证据"（国内直播 App 无官方设计文档，结论以产品功能与社区口碑为准，不引用未经核实的精确数据）。
- **排除项**：广告位、会员引导、弹窗等纯变现设计不在参考范围内。

---

## 二、主流直播类 App 体验拆解

> 证据级别说明：以下 2.1-2.4 基于公开产品形态与用户口碑归纳（国内直播类 App 普遍无官方设计规范，故不列精确数据来源）；TiviMate、my-tv 有官网/仓库可查（见第六节）。

### 2.1 电视家

- **开机即播**：安装后默认频道立即出画，频道列表只是辅助入口；重启回到上次频道。
- **按键心智**：MENU=频道菜单，OK=进入/确认，数字键=频道直拨（1-3 位），上下键=切台，左右键=音量/换线路，SETTINGS=设置。
- **列表体验**：左侧分类（央视/卫视/地方/收藏…），右侧频道列表；当前播放频道在列表中有标识；收藏有独立分组且可聚焦操作。
- **EPG**：节目单展示"现在/接下来"，当前节目高亮；播放页信息卡显示台标+频道名+当前节目+时间。
- **错误恢复**：线路失败自动换源，明显错误提示与恢复入口；加载/缓冲有进度反馈。
- **易用性取向**：面向老人/家庭场景，字号大、操作步数少、反馈直接；广告之外的交互层级普遍较浅。

### 2.2 小鲸直播

- 直播+点播聚合形态；频道分组与收藏体系与电视家近似。
- 播放页信息卡常驻（台标/频道/节目/时间），按 OK 唤出完整控制层。
- 遥控器全键位适配（数字直拨、菜单键、返回分层退出），切台即时反馈（信息卡先出现，画面紧随）。

### 2.3 火星直播

- 强调"自定义源 + 分组 + 收藏 + EPG"；设置项按播放（解码方式/缓冲）、显示（字号/比例）、源管理分组。
- 线路/源切换有明确反馈（Toast/信息条），多线路自动切换。
- 台标与频道信息卡完善，弱网下有缓冲动画而非黑屏。

### 2.4 HDP 直播

- 老牌聚合形态：数字直拨、自定义源、EPG、多线路。
- 焦点清晰（高对比选中态）、行高宽松，10 英尺可读性优先。
- 历史包袱：设置平铺、视觉老旧，但按键逻辑简单直接，学习成本低。

### 2.5 共性结论（对"电视家类"应用，除广告外最被认可的点）

1. **开机即播、秒开**：默认频道立刻出画，不要求先浏览列表。
2. **按键心智统一**：MENU=菜单、SETTINGS=设置、OK=确认/进入、数字=直拨、上下=切台、左右=换源/音量。
3. **当前播放常驻标识**：列表里有"正在播放"标记，切台后能快速找回。
4. **EPG 一眼看懂**："现在/接下来"高亮 + 时间轴式布局；信息卡含频道+节目+时间。
5. **反馈即时可见**：收藏、切源、切台均有明确反馈。
6. **错误可恢复**：断网/坏线有明确错误页 + 重试/换源入口。
7. **设置分组清晰**：按语义分组，10 英尺可读。
8. **加载有交代**：解析/加载有品牌与文案，不黑屏干等。
9. **焦点清晰统一**：一个焦点视觉体系，选中态高对比。

## 三、平台级 TV 设计规范要点

### 3.1 Google TV / Android TV（Leanback）

- **10 英尺 UI**：以 3 米观看距离设计，文字不小于 16-18sp，标题 24sp+；信息密度低。
- **焦点驱动导航**：D-pad/遥控方向键移动焦点（focus），OK 确认；所有可交互元素必须可获得焦点且焦点态高对比。
- **Browse 模式**：行=内容类别，卡片=条目；横向滚动行 + 纵向切换行；当前焦点卡片放大（1.0-1.1x）。
- **沉浸式播放**：播放全屏无干扰；控制层自动隐藏，按 OK/触控板唤出。
- **系统按键约定**：BACK 逐层返回、HOME 回桌面、MENU 应用内菜单、DPAD_CENTER=OK；播放器支持播放/暂停键。
- **电视专用清单**：应用图标/横幅（320x180 banner）、默认焦点项、最少点击深度（任何功能 ≤3 次按键）。

### 3.2 Apple TV（tvOS）

- **焦点分层界面**：焦点头像式高亮（parallax 效果），焦点即"下一步要做什么"的承诺；点击（触控板）执行。
- **文字最小化**：HIG 明确要求大字号、少文字、高对比；正文避免小于 29pt 级别的小字（观看距离大）。
- **安全边距**：内容避开屏幕边缘（TV 有过扫描历史），边距内放置关键 UI。
- **返回心智**：MENU 键=返回上一级（App 内导航），长按 MENU=回桌面。
- **深浅色与强调色**：默认暗色优先，强调色只用于焦点/选中反馈。

### 3.3 Netflix TV

- **行式轮播 + 焦点缩放**：横向行、大卡片、焦点卡片 1.0→1.1x 缩放并抬升（工程博客明确：焦点缩放是 TV 输入的核心反馈）。
- **减少选项**：新 TV UI 隐藏顶部工具栏，按 OK 才唤出，让画面/内容优先（用户指南）。
- **继续观看/我的列表**：跨设备状态持久，开机即达上次观看位置。
- **自动预览**：焦点停留自动播放预览视频（直播场景不适用，但"焦点即预览"思路可参考）。

### 3.4 YouTube TV

- **频道指南（Live Guide）**：左侧频道行 + 右侧横向时间轴；"当前/接下来"节目并排，当前节目高亮、可一键跳转观看。
- **上下键切台**：直播中上下键直接切换频道并显示节目信息浮层（频道+节目+时间）。
- **顶部导航**：首页/库/直播/搜索等一级入口常驻，层级扁平。
- **多视图**：多频道同屏（Mini Player / MultiView），播放不中断。

### 3.5 Amazon Fire TV

- **官方设计指南**（Design and User Experience Guidelines）：D-pad 优先的导航设计、焦点环/高亮、卡片式布局、最小点击深度。
- **可读性**：10 英尺下正文 ≥ 16-18sp、字幕/标签高对比；背景与文字对比度 ≥ 4.5:1（参考 WCAG）。
- **一致性**：全应用统一焦点样式与返回行为；避免嵌套滚动/深层级。

## 四、关键 UX 维度对照表（主流做法 vs 建议）

|---|---|---|
| 开机体验 | 开机即播、回上次频道 | ✅ 已有：缓存秒开+自动起播 |
| 按键映射 | MENU=菜单、SETTINGS=设置、数字=直拨 | ✅ v3.1.0：单按直达+数字空安全 |
| 正在播放标识 | 列表常驻 ▶/色条 | ✅ v3.1.0：青色竖条+加粗+分组圆点 |
| EPG 可读性 | "现在"高亮+徽标+时间轴 | ✅ v3.1.0：徽标+高亮+居中（时间轴留 v3.2+） |
| 收藏反馈 | 可聚焦+即时反馈 | ✅ v3.1.0：心形按钮+Toast |
| 错误恢复 | 错误页+重试/换源 | ✅ v3.1.0：重试按钮+OK 快捷键 |

## 五、最佳实践 Checklist（约 20 条，含优先级）

**P0（崩溃/阻断级）**

1. 任意状态按数字/方向/MENU 键不崩溃、不 ANR
2. 错误/加载/空数据状态都有明确 UI，不黑屏干等
3. 断网/坏线可恢复（重试/换源/切台），不锁死

**P1（核心体验）**

4. 开机即播：默认频道立即出画，回到上次频道
5. MENU/SETTINGS 单按直达对应界面
6. 数字键 1-3 位直拨频道
7. 列表"正在播放"标识常驻、切台后可找回
8. EPG"现在/接下来"高亮，当前节目居中
9. 信息卡：频道+进行中节目+时间范围
10. 收藏可聚焦、有即时反馈（图标+Toast）
11. 错误页有重试入口与按键提示
12. 加载页有品牌与文案
13. 设置按语义分组、字号 ≥16sp、行高 ≥48dp
14. 焦点视觉全应用统一、高对比
15. 退出应用有确认对话框
16. 右键=前进/换线路，不静默触发隐藏操作

**P2（打磨/长尾）**

17. 列表增量刷新（payload），避免整表 notify
18. 触摸手势一次性引导卡
19. LiveData observer 生命周期化，防泄漏
20. 线路详情可展开（域名+完整 URL+健康度）
21. EPG 时间轴式布局（横向滚动）
22. 焦点动画（缩放/缓动）统一
