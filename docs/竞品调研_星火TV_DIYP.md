## 二、星火TV 功能点全清单

> 说明：本清单以公开教程、用户评测、下载站说明为证据基础。凡无一手来源的条目标注「无法核实」。条目格式：功能名称 / 行为描述 / 入口路径 / 证据级别 / 来源 URL。

### 2.1 启动与首屏

1. **安装与启动**
   - 行为描述：第三方下载站提供的版本号说法不一（如「星火直播 v1.0.52/1.0.53」「星火电视 v2.0.2.9」等），均无官方渠道佐证；具体启动流程、首屏布局无法核实。
   - 入口路径：不适用（下载即安装）
   - 证据级别：无法核实（下载站版本号互相矛盾）
   - 来源：S1、S2
2. **首屏布局（频道列表/分组）**
   - 行为描述：社区教程显示主界面为频道分组列表结构（直播源分组、频道列表），但无官方截图与文档确认具体样式。
   - 证据级别：社区口碑；细节无法核实
   - 来源：S5

### 2.2 频道列表与分组

3. **直播源分组管理**
   - 行为描述：教程描述「设置 → 源管理/直播源 → 添加/删除/启用分组」，支持按分组加载频道；具体 UI 文案随版本差异大。
   - 入口路径：设置 → 直播源/源管理/订阅管理（教程口径）
   - 证据级别：社区口碑
   - 来源：S5
4. **同名频道多线路聚合**
   - 行为描述：同一频道名对应多个地址（同一组内），播放时用遥控器左右键或菜单键切换线路；教程普遍称「换线路」。
   - 入口路径：频道列表 → 选中频道 → 播放页左右键/菜单键
   - 证据级别：社区口碑
   - 来源：S5

### 2.3 播放控制

5. **多线路选择器 / 换线路**
   - 行为描述：播放中切换同频道不同源地址，常见按键为遥控左右键；部分教程提到长按确认键弹出线路列表。
   - 证据级别：社区口碑（按键细节各教程不一，无法核实精确行为）
   - 来源：S5
6. **自动换源/播放失败自动切换**
   - 行为描述：社区教程提到「播放失败自动换源」「卡顿自动切换」类设置项；属于聚合直播类 APP 通用能力，星火TV 是否具备及默认值无法核实。
   - 证据级别：无法核实（教程面向通用 IPTV 工具）
   - 来源：S5

### 2.4 EPG / 回看 / 时移

7. **EPG 节目单展示**
   - 行为描述：教程口径为「显示频道当天或未来的节目安排，可按频道、日期查看节目名称和播出时间」；星火TV 是否有独立 EPG 视图无官方确认，公开资料多为通用 IPTV 播放器描述。
   - 入口路径：播放界面呼出节目单/EPG/指南（教程口径）
   - 证据级别：社区口碑；细节无法核实
   - 来源：S8、S17
8. **回看（从 EPG 选择已播节目播放）**
   - 行为描述：能否回看取决于频道源是否提供回看地址（RTSP/回放源）；只有 EPG 而无回看源时只能显示时间表不能回放。
   - 证据级别：社区口碑（通用机制）；星火TV 支持范围无法核实
   - 来源：S5、S8
9. **时移（直播中暂停/快退）**
   - 行为描述：Android TV 时移机制为对直播流短时间缓存，不能长期保存或跨频道；常见操作「直播中按暂停、左方向键或进度条」。
   - 证据级别：官方文档（Android TV 平台机制）+ 社区口碑（星火TV 具体实现无法核实）
   - 来源：S17、S8
10. **EPG 数据来源/时区问题**
    - 行为描述：节目时间不准可能由 EPG 时区、夏令时或源时间戳偏差导致——通用问题，非星火专属。
    - 证据级别：社区口碑
    - 来源：S8

### 2.5 收藏 / 历史

11. **收藏频道**
    - 行为描述：播放中按 OK/菜单键打开频道操作菜单 → 选「收藏」（星号按钮）；或在频道列表长按/按菜单键收藏；收藏后从「收藏」分类快速进入。
    - 入口路径：播放界面 OK/菜单键 → 收藏；频道列表长按
    - 证据级别：社区口碑（教程口径，各版本不一）
    - 来源：S9、S12
12. **最近观看/历史记录**
    - 行为描述：未检索到星火TV 明确的「最近观看/历史」功能的可靠来源。
    - 证据级别：无法核实
    - 来源：无

### 2.6 设置项全清单（逐项）

> 以下均为第三方教程汇总口径（S9/S12），非官方设置文档；不同版本菜单名与默认值无法核实。

13. **播放源设置**
    - 行为描述：切换不同线路；当前线路不能播放时换源；教程建议「播放源：自动」。
    - 入口路径：设置 → 播放源 / 播放界面右键或菜单键
    - 证据级别：社区口碑
    - 来源：S9
14. **解码方式设置**
    - 行为描述：提供「硬解码 / 软解码 / 自动解码」三档；画面花屏、闪退、音画不同步时切换；建议默认「自动」。
    - 入口路径：设置 → 解码方式
    - 证据级别：社区口碑
    - 来源：S9
15. **画面比例设置**
    - 行为描述：常见选项「自动 / 16:9 / 4:3 / 全屏 / 原始比例」。
    - 入口路径：设置 → 画面比例（播放界面菜单）
    - 证据级别：社区口碑
    - 来源：S9
16. **清晰度设置**
    - 行为描述：网络不稳选低清晰度，良好时选高清/超清。
    - 入口路径：设置 → 清晰度
    - 证据级别：社区口碑
    - 来源：S9
17. **缓存/缓冲设置**
    - 行为描述：可增加缓冲时间缓解卡顿，代价是切台变慢。
    - 入口路径：设置 → 缓存/缓冲
    - 证据级别：社区口碑
    - 来源：S9
18. **更新设置**
    - 行为描述：应用内更新（部分版本）；否则需从可信来源重装 APK。
    - 证据级别：社区口碑
    - 来源：S9

### 2.7 自定义源导入

19. **本地 TXT 文件导入**
    - 行为描述：支持 `.txt`/`.m3u`/`.m3u8` 格式；TXT 每行「频道名,地址」或「频道名|地址」，UTF-8 编码（乱码再试 ANSI）；文件放入设备存储/Download 目录或 U 盘。
    - 入口路径：设置 → 频道管理/自定义源 → 添加源/导入本地文件
    - 证据级别：社区口碑（教程口径，S11/S12/S13）
    - 来源：S11、S12、S13
20. **网络/远程地址导入（URL）**
    - 行为描述：将 TXT 上传到服务器/GitHub/Gitee 直链或 NAS，选择「网络导入/远程地址」粘贴直链；需能直接打开文本内容，不能用登录/跳转网页。
    - 入口路径：设置 → 自定义源 → 网络导入/远程地址
    - 证据级别：社区口碑
    - 来源：S11、S12
21. **扫码/JSON/hex 导入**
    - 行为描述：未检索到星火TV 支持扫码、JSON 或 hex 格式导入的可靠来源。
    - 证据级别：无法核实
    - 来源：无
22. **导入失败常见原因**
    - 行为描述：网页地址而非直链、编码乱码、分隔符不兼容、地址失效/地区限制、协议不支持（如 rtmp）、版本不支持网络 TXT、扩展名 `.txt.txt`。
    - 证据级别：社区口碑
    - 来源：S12、S13

### 2.8 系统集成

23. **遥控按键映射（教程口径）**
    - 行为描述：左键打开频道分类/列表；右键打开播放源/节目列表/侧边栏；上下键切换频道；OK 确认或调出菜单；返回退出；菜单键打开设置；数字键部分版本可直拨频道号。
    - 证据级别：社区口碑（教程汇总，各版本不一，无法核实官方按键定义）
    - 来源：S9
24. **开机自启 / PiP / 后台播放**
    - 行为描述：未检索到星火TV 支持开机自启、画中画、后台音频播放的可靠来源。
    - 证据级别：无法核实
    - 来源：无
25. **未知来源安装（系统侧前置条件）**
    - 行为描述：U 盘安装需开启「设置 → 安全 → 安装未知来源应用」权限；安装后应用列表打开。
    - 证据级别：社区口碑（系统通用流程）
    - 来源：S10

### 2.9 错误与异常体验

26. **打开后白屏/闪退**
    - 行为描述：处理建议：重启电视、清除应用缓存（设置 → 应用 → 星火电视 → 存储 → 清除缓存）、检查存储空间、卸载重装、确认 APK 与系统版本兼容。
    - 证据级别：社区口碑
    - 来源：S9
27. **能打开但没有频道**
    - 行为描述：检查网络、退出重进、切换播放源、检查系统日期时间、可能是频道服务暂时不可用。
    - 证据级别：社区口碑
    - 来源：S9
28. **黑屏/一直缓冲/有声音无画面**
    - 行为描述：处理建议：按右键/OK/菜单键换播放源，等待重载；全部源失败则可能是网络、源失效或版本问题。
    - 证据级别：社区口碑

## 四、UX/易用性细节

> 以下逐条附证据；证据级别多为「社区教程/用户评测」，仅 my-tv 系列为官方 README。

### 4.1 布局结构

1. **星火TV：左列表右播放**
   - 行为描述：部分版本频道列表在左侧、播放画面在右侧，左右键在分类与播放间切换；整体为「列表+预览」大屏布局。
   - 证据级别：社区口碑
   - 来源：S9
2. **DIYP：首页即频道列表，播放页覆盖式**
   - 行为描述：进入即频道分组列表；播放为全屏，呼出操作菜单覆盖在画面上；层级为「首页列表 → 设置（接口/EPG）→ 播放」。
   - 证据级别：社区教程
   - 来源：S25、S26
3. **my-tv：极简全屏 + 覆盖式节目单**
   - 行为描述：播放为全屏，左键呼出节目单覆盖层，右键呼出配置；无复杂首页。
   - 证据级别：官方文档（README）
   - 来源：S38
4. **TiviMate / OTT Navigator：指南网格 + 列表组合**
   - 行为描述：TiviMate 以 EPG 网格为核心入口之一；OTT Navigator 提供多列布局、主屏固定分类、多种主题（Android TV 优化）。
   - 证据级别：应用商店页面/用户评测
   - 来源：S32、S34、S43

### 4.2 操作步数与层级深度

5. **EPG 查看步数**
   - 行为描述：my-tv/DIYP 为「左键呼出节目单 → 选择节目」两步；星火TV 教程口径为「播放界面 → 菜单/左键 → 节目单」；层级均 ≤3。
   - 证据级别：官方文档（my-tv）+ 社区教程（DIYP/星火）
   - 来源：S38、S9、S26
6. **换台步数**
   - 行为描述：上下键直接切台（0 步进入），左右键换线路/分组（my-tv-0 支持换台反转自定义方向）；TiviMate/OTT 主要靠分组列表导航。
   - 证据级别：官方文档/社区教程
   - 来源：S38、S9
7. **配置自定义源步数**
   - 行为描述：DIYP「设置 → 接口设置 → 节目地址 → 保存 → 返回刷新」约 3-4 步；my-tv-0 右键进配置约 2-3 步；星火TV 教程「设置 → 自定义源 → 添加」类似。
   - 证据级别：社区教程/官方文档
   - 来源：S25、S38、S12

### 4.3 焦点样式与反馈方式

8. **焦点与确认反馈**
   - 行为描述：公开资料未检索到各 APP 焦点框样式（描边/放大/变色）的具体说明；共同反馈方式为「选中高亮 + OK 确认 + 菜单/返回取消」。
   - 证据级别：无法核实（焦点样式）；社区教程（按键约定）
   - 来源：S9、S38
9. **缓冲与错误反馈**
   - 行为描述：缓冲中显示加载提示；播放失败时星火TV 教程引导「换播放源/清缓存」；OTT Navigator 部分错误提示为英文；DIYP 教程以「节目单不显示/频道打不开」作为可观测信号。
   - 证据级别：社区教程/用户评测
   - 来源：S9、S26、S44

### 4.4 学习成本与上手门槛

10. **门槛对比**
    - 行为描述：my-tv 本体「安装即用」门槛最低；星火TV/DIYP 需要配置源，门槛中等；TiviMate/OTT Navigator 功能多、设置项多，初次使用需时间调整（OTT Navigator 尤甚，选项多、部分设置英文）。
    - 证据级别：官方文档（my-tv）+ 用户评测（OTT/TiviMate）
    - 来源：S28、S44、S34
11. **大列表场景体验**
    - 行为描述：OTT Navigator 对超大播放列表有专门优化（筛选、折叠重复频道、隐藏分类）；TiviMate 建议隐藏不用的分组；低内存盒子大列表加载慢、老设备不流畅（OTT）。
    - 证据级别：用户评测
    - 来源：S43、S34、S44

### 5.2 DIYP影音

- **空壳无源门槛**：不内置直播源，新手不知道去哪填地址（GitHub Issue 中被反复询问）。

  - 证据级别：社区教程

  - 证据级别：社区教程
  - 来源：S25

### 5.3 my-tv

  - 证据级别：官方文档（README）
  - 来源：S38

  - 证据级别：官方文档（README）
  - 来源：S40

### 5.4 TiviMate

- **Premium 付费/激活问题**：官网、Companion App、Google Play 均有人反映无法购买、扣款未激活、激活丢失（社区建议核对购买邮箱、清缓存、重装）。
  - 证据级别：社区口碑
  - 来源：S41
- **订阅续费混乱**：出现意外自动续费、年费上涨等抱怨。
  - 证据级别：社区口碑
  - 来源：S41
- **客服与退款**：Trustpilot 上有延迟回复、模板化排查、退款被忽略的指控（用户指控，未独立核实）。
  - 证据级别：用户评测
  - 来源：S42
- **播放相关问题**：缓冲、Error 458、EPG 错乱、播放列表加载失败、录制提前中断等反馈；其中部分根因在 IPTV 供应商而非播放器。
  - 证据级别：用户评测
  - 来源：S42
- **价格争议**：终身授权价格被认为偏高，另一些用户认为物有所值。
  - 证据级别：社区口碑
  - 来源：S41

### 5.5 OTT Navigator

- **上手门槛高**：功能多、选项多，不是「安装即用」，需要花时间调整首页、频道排列、播放器按钮与分类显示。
  - 证据级别：用户评测
  - 来源：S44
- **设备差异明显**：低内存盒子大列表加载慢、老旧 Android TV 操作不流畅、复杂 Xtream 服务首次同步耗时。
  - 证据级别：用户评测
  - 来源：S44
- **本地化不完整**：部分高级设置、帮助与错误提示仍为英文；中文教程社区不如 TiviMate 统一。
  - 证据级别：用户评测
  - 来源：S44
- **EPG 需要手动校正**：首次设置需手动调整频道与 EPG 匹配关系。
  - 证据级别：应用商店页面/用户评测
  - 来源：S35、S44

### 6.3 设计取舍建议（基于负面口碑反推）

- 默认「安装即用」或极简引导（my-tv 模式），同时保留进阶设置入口（对齐 OTT 深度定制但避免其上手门槛）；公开资料显示 OTT「选项多」是主要抱怨，TiviMate「设置备份/恢复」是正向能力。
- EPG 是否可回看必须在 UI 上区分展示（源无回看地址时不显示可点状态），避免「7 天回看」式的预期落差（DIYP 教训）。
- 大列表（数千频道）场景必须提供隐藏分组、搜索与折叠重复频道，否则低端盒子体验崩塌（OTT/TiviMate 教训）。
- 代理、请求头等进阶配置修改后要即时生效或明确提示重启，避免 my-tv-0「代理需重启」式困惑。
