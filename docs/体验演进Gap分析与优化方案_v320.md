## 一、调研结论浓缩（三份竞品调研的共识）

### 1.1 电视家（官方已停服，对齐"停服前成熟版本"）

- 官方宣传矩阵：央视/卫视/地方直播、回看、时移、节目预约、节目分类搜索、多端一致（S13）
- 频道列表三栏布局：左分类 / 中频道 / 右当前频道预览+分日节目单（前天/昨天/今天/明天）（S33）
- 播放控制栏：确认/菜单/下键唤出，含画面比例（原始/16:9/4:3/全屏）、字幕、音轨（S5）
- 遥控器：CH±切台、数字直拨、OK 开频道列表、返回退出确认（S8/S42）
- 开机即播组合：开机自启动+启动后自动播放+启动进入上次频道（S9/S10）
- 收藏链路：播放页菜单→底部菜单最左添加/取消收藏；收藏分组；启动进入收藏（S34）
- 源管理三件套：U 盘 TXT/M3U 导入、网络直链导入远程更新、UTF-8 容错与乱码提示（S1/S2/S3/S6）
- 时移边界：时移缓存通常仅限本次会话，切频道/退出失效；暂停无进度条=不支持（S37/S39）

### 1.2 星火TV / DIYP / my-tv / TiviMate / OTT Navigator

- 星火TV 无官方官网/开源仓库，公开功能描述仅到「社区口碑」级，不作硬对齐指标
- DIYP 影音：空壳播放器 + 源导入（TXT/本地/U盘/远程接口）+ EPG 配置与匹配排障 + 7 天回看机制 + 台标/背景/公告 + 解码切换
- my-tv：遥控器全键操作、自定义源 TXT/M3U/JSON、分组/频道号/Logo、收藏、二维码远程配置、启动自动更新、请求头
- TiviMate：M3U/Xtream/Stalker、分组与搜索、EPG 网格与修复工具、Catch-up 边界、MultiView、录制、PiP、家长控制、备份、外观定制
- OTT Navigator：多提供商、自动分组、搜索过滤、EPG 手动补充、回看边界、PiP、提醒、字幕多音轨、继续观看

### 1.3 其他主流直播 APP（小鲸/火星/HDP/超级ITV/八爪鱼/猫TV/央视影音/芒果/咪视界）

- HDP 直播是自定义源标杆：U 盘 TXT（`频道名,英文逗号,地址`，UTF-8/ANSI 兼容，.txt 可改 .tv）+ 局域网网页远程管理；"回"字标识区分可回看节目
- 回看普遍存在但**非全频道**：咪咕/猫TV 约 7 天回看；EPG 有节目表 ≠ 能回看
- 开机自启+开机进入上次频道/收藏：小鲸直播明确提供的"老人友好"组合
- 键位体系高度一致：上下切台、左右切分类、OK 调列表、MENU 承载二级功能、数字直拨（火星/HDP）、长按 OK 收藏（小鲸）
- 硬解/软解切换是直播 APP 标配自救手段（小鲸/HDP）
- 央视影音官方参照：直播暂停/时移/回看、官方 EPG、节目预约、多机位、观看历史
- 咪视界：EPG 与回看/预约融合在同一节目单界面，层级优于多数聚合 APP
- 负面口碑共性：源不稳定、版本混乱（纯净版/破解版）、无客服、非官方 APK 安全风险

### 2.3 明确不做（v3.3+ 或不做，附理由）

- 真回看/时移播放（电视家 S13、HDP 7 天回看）：依赖运营商回看源与鉴权，开源聚合场景无法通用实现；本轮仅做 EPG"回看"标识与提示（G8），不假装支持
- 多视图 MultiView（TiviMate）：UI 架构改动大，单独版本承载
- 录制（TiviMate）：超出直播应用定位
- 家长控制/儿童锁（电视家 S27，C 级弱证据）：证据弱 + 改动面大，列入 v3.3 评估
- 节目预约提醒（电视家 S13、OTT Navigator）：需要系统级闹钟/通知，v3.3 评估
- 主题/外观定制（TiviMate）：视觉体系刚统一（v3.1.0），暂不动
- 备份/导出（TiviMate）：v3.3 评估
- 语音搜索（电视家 S40）：系统语音助手依赖，电视端无统一入口，不做
- USB/U 盘源导入（HDP 标杆、电视家 S1）：需要存储权限全流程+文件选择器，v3.3 承载
- 多端账号同步：无账号体系，不做

## 三、优化方案设计（v3.2.0 承载）

原则：**不引入广告；现有功能与性能不退化为前提**；改动面小、可独立回滚；播放内核只做"快速失败/不等待"类收敛，不做架构重写；UI/UX 保持本项目优势，仅补齐缺口。

### 3.1 播放画面修复（G1，用户实测反馈）

- `player.xml` 根布局 ConstraintLayout → FrameLayout：主/备 PlayerView 共用同一套 `FIT + 居中 + 全屏/16:9` 布局参数，杜绝"替换 LayoutParams 丢约束"类比例问题
- 备用视图 z 序置于主视图**之下**：即使备用 Surface 层被设备合成显示，也永远盖不住主画面
- 备用播放器**永不自动起播**：角色交换后立即 `playWhenReady=false`；`prepareStandbyForNextChannel` 在 prepare 前置 false（消除"READY 后自动播放 CCTV2"竞态）
- 回归基线：快速切台仍秒开（备用预加载保留），无覆盖、无比例错误

### 3.2 播放/加载"不等待"（G2/G3，参考 zcode 项目成熟方案）

- **快速失败**：HLS/DASH/Progressive MediaSource 工厂挂 `NoRetryLoadErrorHandlingPolicy`（1 次尝试、无退避），坏线 onPlayerError 1-2s 内到达，进入"同频道换下一条线路" failover
- **首帧看门狗**：播放/换线请求后 8s 未出画（持续 BUFFERING 且无错误事件）→ 标记坏线换下一条；全部线路耗尽才进错误页（语义不变）
- **健康轮询 15s → 2s**：停播检测（2.5s 阈值）及时触发，不再"黑屏 15 秒才反应"
- **换线冷却收紧**：retryCooldown 30s→8s、switchCooldown 15s→8s，坏线恢复节奏对齐主流"卡顿立即换线"
- **自动换线默认开启**（新安装默认 true，已有用户存储值不变）：对齐电视家/DIYP/zcode 默认体验
- **首源并行发现**：首次启动 19 个预置源并行下载（每源 12s 上限），最快可用源出列表；解析/应用仍由 parseMutex 串行，列表不闪断

### 3.3 频道搜索（G4）

- 入口：频道菜单头部新增"搜索"按钮（菜单键唤出后右端可聚焦），同时支持遥控器 `KEYCODE_SEARCH` 直达
- 交互：弹出搜索框 → 遥控器数字/字母键输入 → 实时按频道名过滤（含当前分组与全部频道）→ 方向键选结果 → OK 播放
- 实现：复用 `TVListModel` 过滤；无结果时显示空态文案；不阻塞播放

### 3.4 最近观看（G5）

- 新增 `recent` 持久化（SharedPreferences 存最近 24 个频道 stable id，跨重启保留）
- 频道菜单分组列表最上方（我的收藏之后）插入「最近观看」，进入后按时间倒序展示，OK 播放
- 观看/切台即更新（去重、顶置），上限 24 条

### 3.5 定时关机（G6）

- 设置页"显示与导航"组新增"定时关机"入口：关闭/30/60/90/120 分钟
- 到点：提示 Toast 后 `finishAffinity()` 退出（不做息屏/挂起，保持简单可预期）
- 剩余时间显示在设置页入口文案；重新进入应用自动重置

### 3.6 画面比例选项（G7）

- 设置页"播放与解码"组新增"画面比例"：跟随内容（FIT）/ 16:9 / 4:3 / 铺满（ZOOM）
- 实现：`PlayerView.resizeMode` 映射（FIT/ZOOM），主/备视图同步；默认跟随内容（与现状一致，不退化）

### 3.7 EPG 分日与回看标识（G8）

- 节目单顶部增加日期切换（今天/明天），横向可聚焦切换，数据来自已拉取 EPG（跨日节目）
- 已结束节目行增加"回看"角标（浅色描边文字），OK 聚焦时提示"该频道回看需源支持，当前版本暂不支持直接回看"（诚实提示，不假装功能）
- 保持 v3.1.0 的"现在"徽标/高亮/居中/空态

### 3.8 长尾清理（G9/G10/G11）

- G9 手势引导：首次进入（`gesture_guide_shown` 为空）在设置页显示"手势说明"卡片（触摸设备），一次性
- G10 observer 生命周期化：`MainActivity.kt` throttle() 的 observeForever 改为持有引用 + onDestroy 移除
- G11 清理：设置页删除"测试码/验证用户"入口与其对话框流程（上游残留）；`SOURCE_FILE_SWITCHER_ENABLED=false` 分支保留但不再直调 Toast（走节流通道）

## 四、回归基线（不退化承诺）

每项改动合入前必须通过：

1. 单元测试全绿（ChannelClassifier/ChannelMetadataParser/SourceQuality，60 项 debug+release）
2. 模拟器冷启动：缓存秒出 + 稳定源立即播放；全新安装首源并行导入出列表 ≤ 15s（原最坏 228s）
3. 连续切台 20 次：无覆盖、无比例错误、无黑屏卡顿、无崩溃/ANR；备用预加载仍生效
4. 坏线恢复：死链频道 2-6s 内自动换线（原最坏 30s+），全部线路耗尽后错误页+重试
5. 数字直拨、菜单三级下钻、收藏、EPG、设置页、退出确认全回归
6. 搜索/最近观看/定时关机/画面比例/EPG 分日 新功能逐项实测
7. 内存：快速切台 20 次后无持续 GC 抖动（logcat 观察）

### 6.3 测试中发现并修复的问题

- **搜索字母键失效**：焦点在 RecyclerView 上时字母键被 Activity 层吞掉（Fragment 根监听收不到）。修复：MainActivity.onKey 在搜索浮层可见时转发字母/数字/删除键给 SearchFragment。
