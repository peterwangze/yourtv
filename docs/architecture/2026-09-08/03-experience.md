# UI/UX、遥控器与常用功能规范

状态：待实施的交互规范与低保真草图，不是当前应用截图。对应审计 A01、A16–A22、A24、A26。观看优先级与播放状态机见 [架构设计](02-architecture.md)。

## 1. 观看主流程

应用启动直接进入电视画面：先读本地用户状态和目录，再播放最后一次有效观看的频道。首次安装没有历史时选择内置推荐频道；用户设置了固定开机频道则优先它。默认不先展示门户、源列表、网络测速或全屏加载广告。启动提示只表达当前动作，不把“加载频道”和“连接节目”混为一个进度。

最后观看记录在当前 attempt 已有首帧且有效观看满 20 秒后更新；暂停、后台、缓冲不累计有效时间。快速经过的频道不污染最近观看。每次满足条件的会话都更新 lastPlayed 时间，即便 URL 没变；不能从稳定线路文件的写入时间推断最后观看。用户设置固定启动频道不影响最近观看历史。

开机频道失效时仍停留该频道，有限恢复后给操作入口；不自动跳到别的节目。尚未完成目录加载时，也允许用完整本地 PlaybackRequest 起播，随后补齐相同 channelId 的候选；不能因“只有缓存的一条地址”永久失去其他线路。

主路径只要求五向键和返回键：**打开即观看 → OK 找台 → 方向键定位 → OK 播放 → BACK 回到画面**。搜索、收藏、线路、字幕、定时停止均有可聚焦按钮，菜单键、数字键、长按和手机只作快捷方式。Android TV 对方向导航、可见焦点和可预测返回的要求见 [TV 导航](https://developer.android.com/training/tv/get-started/navigation)、[遥控器支持](https://developer.android.com/training/tv/get-started/controllers)。

## 2. 信息结构

| 入口 | 内容与默认顺序 | 行为 |
|---|---|---|
| OK：频道 | 收藏、最近观看、央视、卫视、本地、全部；顶部搜索，底部管理 | 收藏/最近为空时提供说明及可聚焦操作；不制造空白死路 |
| 本地 | 用户选定省份的频道，提供“更换地区” | 未设置时先选择地区；不用定位接口阻塞，也不猜用户省份 |
| 全部 | 当前分类目录；其他省份、港澳台/海外及用户导入内容可展开 | 保留覆盖能力，默认主导航不被数百个长尾频道占满 |
| 左键：节目单 | 当前正在播放频道，昨/今/明可用日期、当前节目 | 从频道列表进入时可看所聚焦频道的节目，但不因此切台 |
| 右键：快捷操作 | 收藏、返回上一台、线路/画质、比例、音轨/字幕、定时停止、设置 | 第一屏保留常用项，能力缺失的项显示原因或隐藏 |
| 设置 | 观看、频道与源、设备与网络、关于与诊断 | 常规设置先呈现用户语言，解码/代理/原始地址进入高级页 |

频道内容标签、浏览焦点、正在播放标记是三个不同状态。“正在播放”用独立小标记，收藏用星号；焦点离开后播放标记仍留在真实频道。默认列表按用户顺序/明确分类排列，不在观看中按健康分实时重排。隐藏频道不出现在常规换台集合中，但管理页可恢复。

默认上下换台使用该播放会话确认时的有序频道集合（例如收藏），以 playingChannelId 找前后项，不能读取正在浏览的分组。用户进入另一分组并确认播放后才更新换台集合。目录刷新只在下一次换台计算时映射仍存在的 ID，不让集合下标漂移改变当前节目。首尾循环可开关，默认开启并显示目标频道名。

## 3. 画面草图与视觉约束

以 960×540dp 横屏作为设计参考，不把物理 1920×1080 像素直接当 dp。组件内部只做一次密度换算；文本用 sp。参考外边距水平 48dp、垂直 27dp，实际在 720p/1080p/4K、系统字体放大和电视 overscan 上验证。这些数值是产品设计初值，不是平台强制参数。

### 3.1 全屏与状态条

```text
┌──────────────────────────────────────────────────────────┐
│                                                          │
│                       当前电视画面                       │
│                                                          │
│                                                          │
│  001  CCTV-1 综合                              20:16      │
│  正在播出：节目名称               下一个：节目名称         │
│  OK 选台 · 左 节目单 · 右 快捷操作                          │
└──────────────────────────────────────────────────────────┘
```

状态条在起播成功/切台后显示 4 秒，包含频道号、名称、当前节目和时钟；不常驻 ping、码率曲线、巨大台标。节目单未知就省略节目标题，不能编造。开始连接超过 800ms 才显示“正在连接 CCTV-1”；短加载避免闪一下转圈。切线期间保留可保留的最后画面并标注“正在恢复”，引擎无法保留时用安静底色和频道信息兜底。

### 3.2 频道抽屉

```text
┌───────────────────────────┬──────────────────────────────┐
│ 搜索频道         管理     │                              │
│ 收藏   │ 001 CCTV-1   ▶  ☆ │                              │
│ 最近   │ 002 CCTV-2        │          继续播放            │
│ 央视   │[013 CCTV-13 新闻] │                              │
│ 卫视   │ 005 CCTV-5        │                              │
│ 本地   │ ……               │                              │
│ 全部   │                  │                              │
│ 央视 › 频道   OK 播放     │                              │
└───────────────────────────┴──────────────────────────────┘
```

抽屉参考宽 440dp，分类轨约 112dp，频道区使用余宽，最终按长中文台名校准。打开先锚定当前播放频道；它属于隐藏/被删除的来源时，显示可解释的保留条目或最近观看位置。浏览过程不预加载候选视频，不改变背景声音。

右侧快捷抽屉参考宽 320dp；详情页可增宽，但基本操作保持画面可见。EPG 详细页和源管理允许更大覆盖范围，背景播放仍继续，除非用户明确选择暂停。面板内显示本地数据不启动全量探测。

### 3.3 视觉与焦点 token

| 项目 | 首轮规范 |
|---|---|
| 主要文字 / 辅助文字 / 标题 | 22sp / 18sp / 28sp；避免只靠小号灰字提示关键错误 |
| 列表行 / 按钮 | 行高至少 56dp、主要按钮至少 48dp 高；大字体模式按内容增高 |
| 配色 | 深灰近不透明面板；白色正文、浅灰辅助文；焦点明亮描边加填充，播放标记使用独立强调色 |
| 对比 | 主要正文目标至少 4.5:1，焦点轮廓与相邻面目标至少 3:1；在截图及电视上检查，不只凭色值命名 |
| 焦点 | 2–3dp 可见描边，适度填充；不依赖颜色单一变化，不做会移动相邻内容的大缩放 |
| 动画 | 面板约 120–180ms，焦点立即反馈；减少动画模式可关闭；切台反馈不等待退出动画 |
| 台标 | 固定尺寸占位，缓存优先；失败显示简称，不能撑坏列表、拖慢首屏 |
| 长文本 | 主标题单行省略，焦点停留后可展开/滚动；不用所有行同时跑马灯 |

不默认切换 UI 框架。先统一颜色/尺寸资源与组件焦点状态，再替换重复布局；保留稳定的 Surface 容器，浮层重组不能销毁播放器。

## 4. 遥控器按键矩阵

| 当前状态 | 上/下 | 左/右 | OK | BACK |
|---|---|---|---|---|
| 全屏观看/非交互状态条 | 上一台/下一台；按用户反转偏好 | 左节目单；右快捷操作 | 打开频道抽屉 | 关闭尚可见的纯信息条；再次返回按根页面规则退出 |
| 频道抽屉 | 当前列移动 | 左退分类层；右进入分类/频道/操作列 | 分类下钻；频道明确提交播放并收起；按钮执行 | 逐层退到根分类，再关闭抽屉 |
| 快捷操作/线路详情 | 移动选项 | 展开详情或返回上级 | 确认选择；实际换线才创建新 attempt | 退一层，最终回画面 |
| 节目单 | 节目行移动 | 在显式日期/频道控件切换；内容区按焦点图移动 | 打开简介；有已实现回看能力时才允许播放回看 | 返回调用它的页面及原焦点 |
| 搜索 | 屏幕键盘/结果项内移动 | 相邻键/结果区移动，边界有明确出口 | 输入字符、退格或确认结果 | 先关闭系统 IME（若有），再退出搜索并恢复原锚点 |
| 错误操作面板 | 移动按钮 | 移动按钮 | 执行重试/选台/线路/诊断；相同进行中任务去重 | 关闭面板回画面，保留简短失败状态；不暗中再次重试 |
| 设置/源管理 | 移动选项 | 进入详情/按焦点图移动 | 修改或确认 | 退一层；编辑未保存时给保存/放弃选择 |

统一规则：

1. 只有 OverlayHost 栈顶消费导航事件；UI 一次只存在一个交互浮层，子页保留父页焦点锚点。错误以非抢焦点状态通知当前面板，用户关闭面板后再出现恢复操作。
2. 每次按键以 downTime/keyCode/action 归一化，OK/BACK 对一次物理按下只执行一次。不得用 1 秒禁用 BACK 吞掉真实的两次按下；长按 BACK 不重复退出多层。
3. 导航长按可重复移动；换台目标在约 200ms 的短窗口内合并为最后意图，目标频道名立即反馈。停止/释放前一 attempt 后只连接最终目标，不能排队播放沿途所有频道。数字键先输入编号，1.5 秒空闲或 OK 确认，BACK 清除；非法编号显示“没有这个频道”。
4. 交互面板没有自动消失计时器；纯信息条可自动隐藏。用户正在编辑、浏览节目或读错误时不丢焦点。目录刷新以 channelId 锚定，锚点消失时找最近有效邻居并解释，绝不把焦点当播放命令。
5. 根页面 BACK 遵守可预测退出：信息条收起后，下一次 BACK 结束观看并返回系统。用户可开启“退出前确认”；默认不要求记忆双击时限。HOME 交给系统，返回应用恢复同频道。待机、耳机/HDMI 变化和音频焦点按播放生命周期处理。
6. MENU 键作为快捷操作同义入口，INFO 键只展示信息条；长按 OK 可进频道操作但必须有普通按钮替代。无这些键的遥控器可完成全部主流程。

迁移注意：当前右键存在直接换线习惯。新安装默认右键快捷操作；升级用户首次显示一次简短提示，并提供“保留右键切线”偏好。旧模式仍经过 coordinator 的明确用户换线命令，不保留旧 sourceUp 旁路。上下方向偏好和收藏顺序不被重置。

## 5. 搜索、EPG 与频道操作

### 搜索

搜索首屏有可聚焦的本地字母/数字键盘、空格、退格、清空和结果区，五向键无需系统字母键也能输入。支持中文完整名/别名、拼音首字母与数字，如“央视新闻”“cctv13”“ysxw”“13”命中同一频道；先在本地预构建索引，不每次按键联网。中文直接输入可使用可用的系统 IME，系统无 IME 时仍可通过首字母找台。

结果去重按 channelId，不把同频道不同线路显示成一屏重复项。无结果时仍可回到键盘、清空或查看全部频道；不把焦点设给不存在的第一结果。确认前背景节目不变，退出恢复搜索前的分类/滚动位置。语音与手机输入为可选增强，不要求 Google 服务或手机在场。

### EPG

节目页明确频道名称、日期、当前时间线与时区；正在播出用可见标记，未来节目能读简介。数据必须来自该频道 ID；无匹配时显示“暂无节目单”，过期显示“节目单待更新”。刷新按钮可见队列/进度，失败仍保留带日期的旧数据。系统时间明显错误时提供检查设备时间入口，不以第三方时间 API 阻塞直播。

回看、预约和时移只在能力与完整行为实现后出现。首期不把 OK 按在过去节目上伪装成可回看，也不默认将直播暂停扩展为无限时移。

### 频道管理

收藏/取消收藏在快捷面板和频道行操作均可达；保存后立即有一致状态反馈。排序支持“移动到前面/后面”和进入移动模式再方向键调整，不依赖拖拽。隐藏可在管理页撤销。删除订阅预览受影响频道与收藏，收藏保留失效引用，待重新匹配；不能自动收藏同名但不同地区的台。

## 6. 线路、错误与网络文案

用户优先看到“自动选择（优先稳定）”“本次固定线路”“最近播放成功：时间”“本网络较稳定”，原始 URL、HTTP/codec 错误码进入详情。画质显示实际解码轨道信息，未知时标未知，不能用名称含 4K 当已播放 4K。探测 RTT 不能标成切台耗时或稳定度。

固定线路默认仅对本次会话；“记住此频道线路”是独立选择。固定时关闭自动跨线，但保留同线短暂恢复；线路失效后由用户选择“恢复自动”。自动模式中的清晰度偏好不保证存在可降码率流。

| 情况 | 主文案示例 | 可达操作/反馈 |
|---|---|---|
| 首次连接 | 正在连接 CCTV-13 | 仍可 OK 选台、BACK/上下切换；不冻结输入 |
| 同线短暂恢复 | 画面缓冲中，正在恢复 | 800ms 后轻提示；恢复即消失，不循环 toast |
| 自动换线 | 当前线路中断，正在尝试其他线路（2/3） | 分母为本轮计划实际候选上限；次数不无限增长 |
| 网络失联且缓冲耗尽 | 网络已断开，连接恢复后继续本频道 | 选台、网络设置、重试；不把所有源写成失效 |
| 全部自动预算耗尽 | 暂时无法播放 CCTV-13 | 重试、选择线路、换个频道、查看原因；可发起一次相关源更新 |
| 解码失败 | 这条线路的视频格式暂无法在本设备播放 | 兼容线路/画质、诊断；高级软解选项说明可能掉帧 |
| 源更新排队 | 等待播放缓冲充足后更新 | 取消、暂停播放后更新；不能永远只写“成功” |
| 部分订阅失败 | 已更新 3 个来源，2 个沿用上次目录 | 查看失败详情/重试；播放与收藏保留 |
| 缓存目录离线启动 | 当前使用本地频道目录 | 短提示即可，列表照常可用；直播连接另有状态 |
| 定时到期 | 将在 30 秒后停止播放 | 取消本次；触发时先清一次性任务再停止 |

失败面板只解释已掌握的原因；例如连接超时不能直接声称“运营商屏蔽”。错误详情记录本次持续时间、尝试次数、网络状态与可分享的脱敏诊断编号。

## 7. 常用功能范围与默认值

| 功能 | 首期交付要求 | 默认/边界 | 阶段 |
|---|---|---|---|
| 开机继续、固定开机频道、返回上一台 | 使用实际有效观看记录与稳定 ID | 默认继续观看；上一台不占用 BACK | M1/M2 |
| 收藏、最近观看、排序、隐藏 | 重启/刷新/升级保持，五向可达 | 最近 20 个不同频道，允许清空 | M2/M3 |
| 数字直选、本地搜索 | 番号与 ID 分离，无字母键可用 | 首字母搜索本地完成 | M2/M3 |
| 自动/手动线路、画质偏好 | 当前线路、证据时间、次数准确 | 自动优先稳定；失败不偷偷换频道 | M1/M3 |
| EPG | ID 关联、日期/时区、空态和缓存 | 不影响首帧，默认今天 | M2/M3 |
| 比例 | 原始比例、适应屏幕、填充的预览与记忆 | 默认保持原始比例；填充提示裁切 | M3 |
| 音轨/字幕 | 按实际可用轨道展示与选择 | 自动语言、无轨道不出现空选择页 | M3 |
| 定时停止 | 剩余时间、取消、只触发一次 | 默认关闭；不命名“电视关机” | M1/M3 |
| 本地文件/订阅导入 | M3U/TXT/JSON 预览、逐源启用、失败保留旧版 | SAF 选择文件，LAN 源明确标记 | M2 |
| 手机配对配置 | 五向入口、限时配对、导入 job 状态 | 默认不开放常驻写入口 | M2/M3 |
| 诊断导出 | 本地最近会话、脱敏包、设备/网络说明 | 默认不上传 | M0/M3 |
| 回看、时移、录制、语音、后台听电视 | 独立能力与来源验证后再排期 | 首期不扩大观看链路复杂度 | 后续 |

## 8. 端到端体验验收脚本

1. **纯五向找台**：冷启播放 A → OK → 浏览其他分组 B → BACK → 仍播放 A；再搜索 `cctv13` → OK → 仅此时改播 CCTV-13。全程不使用字母键、触摸或手机。
2. **浏览中故障**：播放 A 并浏览 B，注入 A 断流 → B 焦点保持，恢复只在 A 的线路内 → 关闭菜单可操作错误/恢复结果。期间不能出现 B 的声音或画面。
3. **本地能力**：断网冷启 → 1.5 秒目标内出现本地频道/收藏 → 搜索/排序可用；连接直播失败有等待网络说明；恢复网络后同频道一次恢复，无循环跳台。
4. **目录变化**：收藏并播放 A → 导入删除/重命名/排序变化目录 → 当前画面保持；收藏歧义项保留待匹配；取消导入不修改目录，失败有终态。
5. **单线与全坏**：单线路暂时 5xx 能在预算内原地恢复；三条均坏在 20 秒内进入可操作错误态；再次重试去重，BACK 不触发新请求。
6. **生命周期与定时**：HOME 往返、待机唤醒、切换解码设置各一次，恢复同频道且无双音频；定时触发后重开应用不立即再次退出。
7. **可读性与焦点**：长台名、无 EPG、零结果、空收藏、200% 字体、目录刷新、连续两次 BACK 都有可见且可预测的焦点。字幕不被常驻无关 HUD 遮挡。

以上是待执行的验收，不是本次已通过记录。设备和网络量化门槛见 [实施与验收](04-delivery.md)。
