# 播放界面与遥控器交互修复

日期：2026-09-16。基线：`12b420f`（已发布 v3.4.0），修复提交：`dd3d179`。本次为后续修复，尚未发布新版本，未替换已有 Release 附件。

## 修复范围

| 问题 | 实现 |
| --- | --- |
| 菜单、搜索、信息卡用内部稳定 ID 作为台号，出现超长数字和裁切 | 为规范频道列表分配独立显示编号，优先保留有效显式台号，重复或缺省台号分配空闲编号；绘制按宽度缩放。数字选台查找同一编号，避免收藏分组造成位置偏移。 |
| 播放界面左右键含义不一致 | 左键上一线路，右键下一线路，首尾循环；单线路维持当前播放并提示。保留 2 秒换线防抖。上下键切频道，保留换台反转设置。自动故障恢复仍交由播放协调器。 |
| 时钟盖住设置开关，多个浮层遮挡、抢焦点 | 根据可见面板统一隐藏观看时钟和信息卡；面板保持在错误页之上，关闭后恢复错误状态；播放器更新不再抢占面板焦点。 |
| 菜单遮挡过大、顶部功能不易到达 | 菜单宽度跟随分组和频道列，顶部提供节目单、设置、搜索；频道列表首行可向上进入工具栏。 |
| 设置打开后跳到底部，按钮被压成窄列 | 初始焦点放在常用播放设置并回到顶部；保留全宽按钮的布局，失焦文字保持可读。 |
| 搜索缺少可编辑输入框 | 使用 EditText 接入系统输入法；OK 唤起键盘，下键进入结果，结果 OK 播放，上键可回到输入框。字母数字输入实时过滤，返回关闭搜索。 |
| 空节目单仅 Toast，无法刷新、切日期 | 无数据也展示节目单面板、今天/明天和刷新/设置入口；区分未配置、未加载、加载中、失败、当天无节目。移除 5 秒自动关闭；刷新结果不抢走按钮焦点。 |
| 外部校时偏移长期残留 | 时钟和节目单统一使用 Android 设备时间及设备时区，取消启动时外部校时请求。 |

错误页还保存视图创建前传入的错误信息，避免首次显示时丢失说明。台号分配不修改持久化频道 ID；搜索、收藏、最近观看仍共用规范频道对象。

## 观看与网络约束

面板操作、台号分配、输入过滤和线路索引切换在本地完成。没有新增源列表下载、批量探测或备用播放器。

自动 EPG 刷新继续在观看期间让路；用户明确选择刷新时允许加载节目单，同一时刻仅运行一个任务，单次 HTTP 调用设置 12 秒上限。已有镜像回退可能产生多次调用，因此 12 秒不是整个刷新流程的总时限。新播放或生命周期取消继续取消后台维护任务。

手动相邻换线尊重用户选择，可能选到当前网络不可用的线路；这不代表每条线路都可播放。本次未进行电信、联通、移动三个真实接入网络的覆盖测试。
