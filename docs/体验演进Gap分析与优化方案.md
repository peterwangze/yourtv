## 一、主流体验结论（电视家 / 星火TV / DIYP / TiviMate 等）

详细拆解见 [主流电视UIUX调研.md](主流电视UIUX调研.md)。对"电视家类"应用，用户体感最核心的几条（除广告外）：

1. **开机即播**：安装后默认频道立刻出画，频道列表只是辅助（本应用已具备：秒开 + 自动起播）。
2. **按键心智统一**：MENU=菜单、SETTINGS=设置、OK=确认/进入、方向键=导航、数字键=频道直拨（本应用 MENU/SETTINGS 单按无反应，违背心智）。
3. **当前播放常驻标识**：列表里有"正在播放"标记，切台后能快速找回（本应用缺失）。
4. **EPG 一眼看懂**："现在/接下来"高亮 + 时间轴式布局（本应用仅文字变色、定位顶对齐）。
5. **反馈即时可见**：收藏、切源、切台都有明确反馈（本应用右键收藏静默无反馈）。
6. **错误可恢复**：断网/坏线时有明确错误页 + 重试入口（本应用错误页静态无操作）。
7. **设置分组清晰**：按语义分组，10 英尺可读（本应用 23 项平铺一页、14sp 小字）。
8. **加载有交代**：解析/加载有品牌与文案，不黑屏干等（本应用黑屏+转圈）。

## 三、优化方案设计（v3.1.0 承载）

原则：**只动体验，不动播放内核与数据管道**；每项改动面小、可独立回滚；全部改动后跑完整回归基线。

### 3.1 按键映射恢复主流心智（F3 + F10）

- MENU 单按 → 打开频道菜单；SETTINGS 单按 → 打开设置。保留"4 连击"仅作为触屏隐藏快捷入口，不再作为唯一入口。
- ENTER/OK：频道菜单可见时由菜单消费；EPG（ProgramFragment）可见时 → 关闭 EPG（或选中当前节目）；设置页可见 → 触发焦点按钮点击；其余维持 600ms 菜单逻辑。
- 移除 OK 四连击开 sourceSelectFragment 的隐藏手势（与主流心智冲突且无必要）。
- 触摸单击 → 显示/隐藏信息卡（保持简单可预期），双击 → 菜单，长按 → EPG。

### 3.2 列表体验（F4 + F5）

- 移除 DPAD_RIGHT 静默收藏；右键恢复"前进"语义（不消费，交由上级处理）。
- 收藏改为可聚焦心形按钮：`focusable=true`，聚焦时显示焦点背景，OK/点击切换收藏并立即更新图标 + Toast 反馈（"已收藏 XX"/"已取消收藏 XX"）。
- 列表行增加"正在播放"标识：`list_item.xml` 新增左侧青色竖条/▶ 图标，绑定 `positionPlayingValue`；当前播放行标题加粗白色。分组行若含当前频道，显示小圆点。

### 3.3 EPG 可读性（F6 + F21 + F10）

- `ProgramAdapter` 当前节目行（index）：高亮背景（青色 10% 填充）+ "现在"徽标 + 时间文字；定位改为 `scrollToPositionWithOffset(index, 行高/2)` 居中。
- `ProgramFragment`：adapter/layoutManager 懒初始化一次；`onVisible` 仅更新数据（`notifyDataSetChanged`）与滚动；空 EPG 显示"暂无节目单"空态文案；去掉每次重建。
- Activity ENTER 分支：`programFragment` 可见时短路为关闭 EPG。

### 3.4 错误/加载状态（F2 + F16 + F17）

- `ErrorFragment`：删除第二次 inflate；消息支持换行；增加"重试"按钮（触发换线/重新播放）+ 下方提示"按 OK 重试 / 按返回退出"；ENTER/OK 在错误页可见时触发重试回调。
- `loading.xml`：加品牌 Logo（复用 `logo0.png`）+ "正在加载频道列表…"文案 + 进度条；`LoadingFragment` 死代码 `removeFragment` 清理。

### 3.5 信息卡（F12）

- EPG 过滤改为 `beginTime < now && endTime > now`（找不到当前节目时回退最近一个已结束节目，标注时间）；desc 显示 "HH:mm-HH:mm 节目名"。
- 位图创建移到 Fragment 字段一次性懒加载（复用），切台不再每次新建 Bitmap。

### 3.6 设置页轻量分组 + 修复（F7 + F8 + F9）

- `setting.xml` 增加 4 个分组标题（播放与解码 / 显示与导航 / 网络与源 / 关于与退出），条目按语义归组；开关文字 14sp → 16sp，按钮行高提升。
- "退出"开关删除，改为"退出应用"按钮 + 确认对话框（复用 dialog_confirmation）。
- `YourTVApplication.kt:73` 删除 `SP.compactMenu = true` 强制覆盖；首次安装默认值交给 `SP.DEFAULT_COMPACT_MENU`。

### 3.7 焦点视觉统一（F11，轻量版）

- 新增 `focus_item_background.xml`：`state_focused` = 青色描边（`#0096A6` 2dp）+ 半透明青填充 + 8dp 圆角；列表行/分组行/EPG 行/设置条目统一引用。
- 列表行聚焦时保留整行变色 + 描边，不再依赖纯色块；`button_scale.xml` 应用到设置按钮（1.05x 缩放）。
- 删除未引用的 `item_background.xml`（粉色）与 `focus_background.xml`（holo_blue）或替换为统一色板。

### 3.8 小项修复（F13/F14/F19/F22，低风险顺手项）

- F13：紧凑宽度统一为 `groupWidth * 4 / 5`，抽成常量。
- F14：分组列表顶部 UP 改为环绕到底部（与底部 DOWN 环绕对称），移除对 GONE 控件的 nextFocusUp。
- F19：切源/切线路提示统一走 `YourTVApplication.toast()` 节流通道（SourceSelectFragment 保留自己节流）。
- F22：线路编号 1 起；标题加"线路 N · 域名"摘要，URL 完整显示（多行、可聚焦展开）。

### 3.9 明确不做（本版本）

- F7 的二级页重构、F11 全量视觉重做、F15 增量刷新改造、F18 手势引导卡、F20 observer 重构、F23 死代码删除 → 列入 v3.2.0/v3.3.0 长尾（见版本规划），避免本版本改动面失控。

## 四、回归基线（不退化承诺）

每项改动合入前必须通过：

1. 单元测试全绿（ChannelClassifier / SourceQuality / ChannelMetadataParser 共 30 项）。
2. 模拟器（emulator-5554）冷启动：缓存秒出 + 稳定源立即播放；首启解析 ≤45s。
3. 上下键连续切台 20 次：无卡顿、无闪黑、无崩溃；备用播放器预加载仍生效（切台无黑屏停顿）。
4. 数字直拨 1-3 位、双击 BACK 退出；数字键在任意状态不崩溃（含列表未就绪）。
5. 菜单三级下钻（地方›省份›频道）与逐级返回；重开菜单定位当前频道。
6. 收藏增删即时反映到"我的收藏"；右键不再误收藏。
7. MENU/SETTINGS 单按直达；EPG 打开时 OK 不再弹菜单。
8. 错误恢复：断网 → 错误页 → 重试/切台恢复；错误页在 4K 分辨率下文字缩放正确。
9. EPG 当前节目高亮居中、空 EPG 有文案；信息卡显示进行中节目且含时间。
10. 内存：快速切台 20 次后无持续 GC 抖动（logcat 观察）。

### 6.2 回归基线实测（全部通过）

1. 单元测试 30/30 全绿（ChannelClassifier 14 + ChannelMetadataParser 13 + SourceQuality 3）。
2. 全新安装：加载页（Logo+文案+进度条）正常显示，首启约 40s 内出频道列表并起播 CCTV1；二次启动缓存秒开。
3. 快速切台：上下键交替 20 次无卡顿/无闪黑/无崩溃（模拟器实测 CCTV10↔CCTV11 约 1s/次，备用播放器预加载生效）。
4. 数字直拨：输入 12 正常显示频道号浮层；任意状态不崩溃。
5. 菜单三级下钻（其他›体育频道›频道）与逐级返回正常；重开菜单定位当前频道。
6. 收藏：右键聚焦心形 → OK 收藏 → 图标变红 + Toast → 我的收藏分组出现该频道；重启后收藏持久。
7. MENU 单按直达菜单、OK 在 EPG 打开时关闭 EPG（不再弹菜单）、右键=换线路（"线路 2 / 5"提示）。
8. 错误恢复：死链频道（2 条线路均失败）→ "All lines failed" → 错误页（图标+重试按钮+提示）→ 恢复源后 OK 重试 → CCTV1 恢复播放。
9. EPG：当前节目"现在"徽标 + 高亮居中；信息卡显示"06:56-07:45 主角24/48"式进行中节目。
10. 退出确认：设置页"退出应用"按钮 → 确认对话框（取消可退回，应用不退出）。

### 6.3 测试中发现并修复的问题

- **启动聚合窗口 ANR（v3.0.0 遗留，本次测试暴露）**：`MainViewModel.applyChannelList` 的频道排序在 `Dispatchers.Main` 执行，比较器反复调用 `ChannelClassifier.classify`（上千频道×数十次字符串匹配），聚合窗口内按 MENU/方向键即触发"Input dispatching timed out"（ANR 栈证据：`ChannelClassifier.matchProvince` + `sortedWith` 在主线程，CPU 129-203%）。修复：① `classify` 结果加 4096 上限 LRU 缓存（纯函数，语义不变）；② 模型构建/合并/排序/分组整体移入 `withContext(Dispatchers.Default)`，主线程只做 LiveData/分组模型应用。修复后聚合窗口内连续按键无 ANR（进程存活、logcat 无 ANR 记录）。
- **加载页被播放器遮挡**：加载页 add 顺序在播放器之前导致 Logo/文案不可见（视觉只剩进度条）；将加载页移到 Fragment 栈顶层后正常显示。
- **模拟器 SETTINGS 键被系统拦截**：Android TV 参考镜像上 KEYCODE_SETTINGS 由系统消费（打开系统设置），据此为菜单头部增加"设置"入口，兼容 Google TV 类设备。

### 6.4 测试辅助工具
