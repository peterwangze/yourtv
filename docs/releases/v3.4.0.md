# v3.4.0 播放恢复与国内网络源治理

聚源TV 3.4.0（versionCode 340），Android 6.0 / API 23 及以上。

## 主要更新

- 统一播放会话、首帧等待和失败恢复，限制单次尝试与总恢复时间；修复手动换线后回退、重复重试和前后台恢复的状态同步。
- 校验首帧所属的媒体与尝试，减少旧回调干扰；明确支持纯音频源的起播判定。
- 观看期间减少源刷新、批量探测和预加载竞争，优先使用内置快照与缓存；按线路播放健康度排序，并保留不同运营商候选。
- 汇集自 v3.1.0 以来的频道搜索、最近观看、定时关机、画面比例、分日节目单、聚合与分类改进。

## 已知问题与验证范围

- **P1：冷启动恢复历史稳定线路，该线路失败时可能只剩黑屏和时钟，缺少错误及重试入口。**
- **P2：手动导入的局域网地址可能被公共源过滤策略删除。**
- Android TV API 36 Debug 设备测试覆盖了坏线切换、重复超时、重试恢复、HOME 往返、熄屏恢复和纯音频起播。部分过程发生过可恢复的源错误，不能描述为全程无卡顿。
- 尚未完成大陆电信、联通、移动三网实测，真实断网/默认网络切换、API 23 和低端实体电视也未完整验收。此版本不宣称整体验收通过。

完整问题与证据：[模拟器 QA 报告](https://github.com/peterwangze/yourtv/blob/v3.4.0/docs/reviews/2026-09-11-android-tv-emulator-qa.md)。播放实现变更见[修复记录](https://github.com/peterwangze/yourtv/blob/v3.4.0/docs/reviews/2026-09-11-playback-review-fixes.md)。
