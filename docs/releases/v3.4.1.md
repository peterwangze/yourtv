# v3.4.1 高清优先与电视交互修复

聚源TV 3.4.1（versionCode 341），Android 6.0 / API 23 及以上。

## 主要更新

- 优先实测 1920×1080 及以上线路，修复历史低清稳定线路长期占据首选的问题；冷启动使用完整频道候选列表，避免仅恢复旧单线路。
- 内置 79 条线路的离线视频尺寸记录，结合本机首帧耗时和稳定播放表现选线；保留不同主机及电信、联通、移动候选，网络路径变化后重新学习健康状态。
- 优先尝试已知高清候选，失败后允许低清兼容线路；实际画面不足 1080P 时明确显示分辨率与提示，避免把域名或“HD”标题当作高清证明。
- 播放界面左键上一线路、右键下一线路，上下键切换频道；OK / MENU 打开频道菜单，保留换台反转设置。
- 修复超长台号、数字选台与收藏分组关联、时钟遮挡、设置焦点及按钮尺寸；完善搜索输入、节目单空状态和刷新入口。

## 验证范围与已知限制

- 此前已完成 Android TV API 36 上实际 1080P 播放及低清提示验证。CCTV2 实测候选首帧约 1.68 秒；源采样共覆盖 26 个频道、102 个 URL，其中 63 个当时返回全高清或以上尺寸。
- 公共源可能过期、跨运营商不可达或波动，尺寸也不等于有效码率和画质保证。**成都三网晚高峰长稳测试、API 23 和低端实体电视尚未完整验收**，不承诺所有频道持续 1080P 或无卡顿。
- 继承的已知限制：手动导入的局域网源可能被公共源过滤策略删除。
- 质量快照 30 天过期，之后依靠本机播放记录及候选线索；实时观看仍需持续网络带宽。

详细证据：[高清选线报告](https://github.com/peterwangze/yourtv/blob/v3.4.1/docs/reviews/2026-09-17-fullhd-source-quality.md)、[界面与遥控器报告](https://github.com/peterwangze/yourtv/blob/v3.4.1/docs/reviews/2026-09-16-tv-ui-and-remote-fixes.md)。报告中的 3.4.0 APK 是当时的测试包，本次发行附件为独立递增版本的 3.4.1。
